# 시나리오 로그 (M3-4)

BCM 상태 머신(M4)을 검증하기 위한 주행 시나리오. **TDD의 인수 테스트**처럼, 여기 적은 "기대 결과"를 M4가 만족해야 한다.
`make test`의 `tests/test_scenarios.c`가 7개 파일을 전부 돌려서 상태 전이의 시각과 규칙을 자동으로 확인한다 (M4-7).

- 형식: `docs/log-format.md` (candump `-l`). **주석 없음** (M3-1 결정)
- 생성: `make scenarios` (`tools/gen_scenarios.c`가 `can_set_bits()`로 만든다. 손으로 고치지 말고 생성기를 고칠 것)
- 실행: `./build/bcm_sim --file data/scenarios/01_normal_drive.log`
- 모든 메시지는 100ms 주기 (0x300 → 0x200 → 0x100 순서). 시각은 0초부터

> 아래 "기대 BCM 동작"은 [docs/fsm-design.md](../../docs/fsm-design.md)의 상태 전이 표(T1~T11) 기준이다 (M4-1에서 확정).
> 요약: IDLE → **DRIVING_LOCKED**: 시동 ON + 15 km/h 이상 + 문 전부 닫힘 / DRIVING_LOCKED → **WARNING**: 문 열림 + 3 km/h 초과, 또는 신호 이상(Fail-safe) / WARNING → 문 전부 닫히면 원래 상태로 / → **IDLE**: 0 km/h + P단, 또는 시동 OFF/ACC

## 01_normal_drive.log — 정상 주행

| 시각 | 상황 |
| --- | --- |
| 0.0초 | 시동 OFF, P, 0 km/h, 문 닫힘 |
| 0.5초 | 시동 ON |
| 1.0초 | 기어 D, 가속 시작 (100ms마다 +2 km/h) |
| 1.8초 | 16 km/h (처음으로 15 km/h 이상) |
| 4.0 ~ 6.0초 | 60 km/h 정속 |
| 6.0 ~ 9.0초 | 감속 (100ms마다 -2 km/h) → 9.0초 0 km/h |
| 9.5초 | 기어 P |
| 10.0초 | 시동 OFF (10.5초까지 기록) |

- 줄 수: 318 (106시점 × 3메시지), 오류 0
- **기대 BCM 동작:** IDLE → **1.8초 DRIVING_LOCKED** (도어 잠금 명령 1회) → **9.5초 IDLE**. 경고음 없음

## 02_door_open_while_driving.log — 주행 중 운전석 문 열림

| 시각 | 상황 |
| --- | --- |
| 0.5초 / 1.0초 | 시동 ON / 기어 D, 가속 시작 (100ms마다 +2 km/h) |
| 1.8초 | 16 km/h |
| 3.0 ~ 7.0초 | 40 km/h 정속 |
| **4.0 ~ 4.9초** | **운전석(FL) 문 열림** (`200#01`) |
| 5.0초 | 문 닫힘 |
| 7.0 ~ 9.0초 | 감속 → 9.0초 0 km/h |
| 9.5초 / 10.0초 | P / 시동 OFF |

- 줄 수: 318, 오류 0
- **기대 BCM 동작:** 1.8초 DRIVING_LOCKED → **4.2초 WARNING (경고음 ON)** → **5.2초 DRIVING_LOCKED (경고음 OFF)** → 9.5초 IDLE
- 문은 4.0초에 열렸지만 디바운싱(M4-5, 도어 프레임 3개 연속 확인) 때문에 4.0, 4.1, 4.2초 프레임을 본 뒤 **4.2초**에 인정한다. 닫힐 때도 5.0, 5.1, 5.2초

## 03_signal_timeout.log — 주행 중 차속 신호 끊김

| 시각 | 상황 |
| --- | --- |
| 0.5초 / 1.0초 | 시동 ON / 기어 D, 가속 시작 (100ms마다 +5 km/h) |
| 1.3초 | 15 km/h |
| 2.0 ~ 5.0초 | 50 km/h (실제로 달리는 중) |
| 2.9초 | 마지막 차속 메시지 |
| **3.0 ~ 3.9초** | **0x100(차속)만 안 옴** (0x300, 0x200은 계속 옴) |
| 4.0초 | 차속 메시지 다시 옴 (50 km/h) |
| 5.0 ~ 7.0초 | 감속 → 7.0초 0 km/h |
| 7.5초 / 8.0초 | P / 시동 OFF |

- 줄 수: 248 (차속 10줄 빠짐), 오류 0
- **기대 BCM 동작:** 1.3초 DRIVING_LOCKED → 마지막 수신(2.9초)에서 500ms를 넘긴 **3.5초에 타임아웃 감지 → WARNING (Fail-safe)** → 차속이 4.0초부터 다시 오지만 정상 3프레임(4.0, 4.1, 4.2초)을 확인한 **4.2초에 복귀 → DRIVING_LOCKED** (M4-6) → 7.5초 IDLE
- 로그: `[3.500s] WARN 신호 끊김: 차속 (마지막 수신 2.900s)`, `[4.200s] INFO 신호 복귀: 차속`
- 핵심: 마지막 차속(50 km/h)을 계속 믿으면 안 된다. "모름"이 됐다는 걸 알아채야 한다 (M4-6)

## 04_invalid_frames.log — 이상한 프레임 섞임 (파일 모드 전용)

30 km/h로 짧게 주행하면서 중간에 이상한 줄과 이상한 값을 끼워 넣었다.

| 시각 | 끼워 넣은 것 | 기대 처리 |
| --- | --- | --- |
| 1.51초 | `555#AABBCCDD` | 관심 없는 ID → 디스패처 IGNORED |
| 1.61초 | `100#10` (차속인데 DLC 1) | 파싱 OK → 디스패처 ERROR, 이전 차속 유지 |
| 1.71초 | `100#10G7...` | 파서 ERR_DATA |
| **1.8초** | **차속 `FFFF` (무효값)** | 디스패처 OK, `speed.valid = false` → BCM은 "차속 모름" |
| 1.91초 | `100#102` | 파서 ERR_DATA |
| 2.01초 | `800#00` (ID > 0x7FF) | 파싱 OK → 디스패처 ERROR (`can_frame_is_valid`) |
| 2.11초 | `100#R` | 파서 ERR_UNSUPPORTED |
| **2.2초** | **기어 `7` (무효값)** | 디스패처 OK, `gear = GEAR_INVALID` |
| 2.3초 근처 | `garbage line` | 파서 ERR_TIMESTAMP |
| 2.41초 | `400#01010000...` (우리 BCM 메시지) | 디스패처 IGNORED |

- 줄 수: 137 (정상 129 + 끼워 넣은 8), 실행 결과: `read 137, ok 133, error 4`, 디스패처 `ok=129 ignored=2 error=2`
- **기대 BCM 동작:** 0.8초 DRIVING_LOCKED → **1.8초 WARNING** (차속 무효 = 신호 이상, Fail-safe) → **2.1초 DRIVING_LOCKED** (정상 차속 1.9, 2.0, 2.1초 3프레임 뒤 복귀, M4-6) → 3.8초 IDLE (정차 + P). 2.2초 기어 무효는 상태 변화 없음 (기어는 정차 후 IDLE 복귀 판단에만 쓴다). 깨진 줄로는 상태가 바뀌지 않는다
- ⚠️ can-utils(`log2long`, `canplayer`)는 첫 깨진 줄에서 멈춘다 → **M5 재생에는 01~03만** 쓴다

## 05_speed_jitter.log — 15 km/h 근처에서 속도가 흔들림 (M4-4)

막히는 길에서 15 km/h 근처를 오락가락하는 상황. **히스테리시스**(fsm-design.md 7번) 검증용.

| 시각 | 상황 |
| --- | --- |
| 0.5초 / 1.0초 | 시동 ON / 기어 D, 가속 시작 |
| 1.0 ~ 1.7초 | 0 → 14 km/h |
| **1.8 ~ 4.7초** | **14.90 ↔ 15.10 km/h를 100ms마다 번갈아** (30번) |
| 4.8 ~ 5.7초 | 30 km/h까지 가속 |
| 5.8 ~ 7.0초 | 감속 → 7.0초 0 km/h (15 km/h를 한 번 더 지나감) |
| 7.5초 / 8.0초 | P / 시동 OFF |

- 줄 수: 258 (86시점 × 3메시지), 오류 0
- **기대 BCM 동작:** **1.9초 DRIVING_LOCKED** (처음으로 15.10, **잠금 명령 1회**) → 14.90으로 떨어져도, 감속하며 15 아래로 내려가도 **그대로** → 7.5초 IDLE (0 km/h + P). 상태 전이 2회
- 해제 문턱이 15 km/h였다면: 100ms마다 잠금/해제 반복 → 잠금 명령 16회

## 06_door_noise.log — 도어 신호 노이즈 (M4-5)

40 km/h로 달리는 중 도어 신호가 한두 프레임씩 튄다. **디바운싱** 검증용.

| 시각 | 도어 프레임 (0x200) | 진짜인가 |
| --- | --- | --- |
| 0.5초 / 1.0초 | 시동 ON / 기어 D, 가속 (1.0 ~ 2.0초 0 → 40 km/h) | |
| 3.0초 | FL 열림 **1프레임** | 노이즈 |
| 3.5 ~ 3.6초 | FL 열림 **2프레임** | 노이즈 |
| 4.0초 | 트렁크 열림 1프레임 | 노이즈 |
| 4.4 / 4.5 / 4.6초 | FL / **RR** / FL 1프레임씩 (다른 문이 번갈아) | 노이즈 |
| **5.0 ~ 5.9초** | **FL 열림 10프레임** | **진짜** |
| 7.0 ~ 9.0초 / 9.5초 / 10.0초 | 감속 → 정차 / P / 시동 OFF | |

- 줄 수: 318, 오류 0
- **기대 BCM 동작:** 1.4초 DRIVING_LOCKED → 노이즈 전부 무시 → **5.2초 WARNING** (5.0, 5.1, 5.2초 3프레임) → **6.2초 DRIVING_LOCKED** (닫힘 6.0, 6.1, 6.2초) → 9.5초 IDLE. 상태 전이 4회
- 4.4 ~ 4.6초: FL이 2번 튀었지만 **연속이 아니다** (사이에 RR). 문마다 따로 세니까 FL도 RR도 3번이 안 된다

## 07_speed_flapping.log — 차속 신호가 들락날락 (M4-6)

접촉 불량으로 차속(0x100)이 끊겼다 왔다 하는 상황. **끊긴 신호의 복귀 조건** 검증용.

| 시각 | 상황 |
| --- | --- |
| 0.5초 / 1.0초 | 시동 ON / 기어 D, 가속 (1.0 ~ 2.0초 0 → 50 km/h) |
| 2.0 ~ 7.0초 | 50 km/h |
| **3.0 ~ 5.9초** | **0x100이 600ms마다 한 번만 옴** (3.0, 3.6, 4.2, 4.8, 5.4초). 0x300, 0x200은 계속 옴 |
| 6.0초 ~ | 0x100 다시 100ms마다 정상 |
| 7.0 ~ 9.0초 / 9.5초 / 10.0초 | 감속 → 정차 / P / 시동 OFF |

- 줄 수: 293 (차속 25줄 빠짐), 오류 0
- **기대 BCM 동작:** 1.3초 DRIVING_LOCKED → **3.6초 WARNING** (3.0초 수신 후 600ms, Fail-safe) → 3.6 ~ 5.4초에 차속이 한 프레임씩 와도 **경고 유지** (다음 프레임 전에 또 600ms 끊기니까 3개 연속이 안 됨) → **6.2초 DRIVING_LOCKED** (6.0, 6.1, 6.2초 정상 3개) → 9.5초 IDLE. 상태 전이 4회
- 복귀를 프레임 1개로 했다면: 3.6, 4.2, 4.8, 5.4, 6.0초마다 "끊김 → 경고 → 바로 복귀"가 반복 → 상태 전이 12회 (경고음이 0.1초씩 깜빡임)
